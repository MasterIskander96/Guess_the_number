# Guess the Number 🎯

A simple console game where the player tries to guess a randomly generated number.

## 📌 About the Project

**Guess the Number** is my first programming project.
The goal of the game is to guess the secret number chosen by the computer.

The game gives hints after each attempt and tells the player whether the guessed number is too high or too low.

## 🎮 Features

* 🎲 Generates a random secret number
* 🔢 Allows the player to enter guesses
* ⬆️ Tells the player if the guess is too high
* ⬇️ Tells the player if the guess is too low
* ✅ Detects when the correct number is guessed
* 🔄 Simple and easy-to-understand gameplay

## 🕹️ How to Play

1. Start the program.
2. The computer generates a random number.
3. Enter your guess.
4. Follow the hints.
5. Keep guessing until you find the correct number.
6. Try to win using as few attempts as possible!

## 💻 Technologies
